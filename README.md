# SQL Assignment

## Overview

This repository contains solutions for a SQL assignment based on an E-Commerce database schema.

## Topics Covered

* Basic SQL Queries
* Filtering and Sorting
* Aggregations
* Joins
* CASE Statements
* Constraints
* Indexes
* ACID Properties
* Transactions

## Folder Structure

Section_A - Basic Queries (Q1-Q6)

Section_B - Filtering Queries (Q7-Q12)

Section_C - Aggregation Queries (Q13-Q18)

Section_D - Joins and Relationships (Q19-Q23)

Section_E - Advanced SQL Concepts (Q24-Q27)

## Tools Used

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)
